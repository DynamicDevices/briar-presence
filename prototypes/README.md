# Prototypes

Disposable experiments live here, separate from the design source and future
production code. Every prototype must clearly state whether it is simulated.

`legacy-line-study/` preserves the first, superseded standalone HTML demo and
six-frame SVG concept sheet. They were made before Alex requested clustered
light. They are historical reference, not a design decision or real status.

No server is needed: open `legacy-line-study/briar-face-demo.html` as a local
file. No microphone, camera or live harness connection is present.
